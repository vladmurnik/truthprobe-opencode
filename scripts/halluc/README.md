# Детектор выдумок: как воспроизвести замер

Данные в репозиторий не входят: это 20 МБ ответов с токенами. Ниже порядок шагов —
именно в этом порядке, иначе признаки посчитаются по испорченному набору.

1. `collect3.py` — 31 вопрос с ловушкой × 4 модели через OpenAI-совместимый шлюз
   (`OPENCODE_BASE` по умолчанию `http://127.0.0.1:8790/v1`); транспорт берётся из
   `/home/adik/halluc/collect.py`, поэтому положите рядом и его, либо задайте `HALLUC_DIR`.
   Пишет `rows_raw3.jsonl`, метки трёхзначные, возобновляется по паре `(model, qid)`.
2. **`repair.py`** — восстанавливает текст ответов, которые коллектор сохранил с пустым
   `answer` при живых токенах, и переразмечает их теми же правилами. Пишет `rows_raw2f.jsonl`
   и `rows_raw3f.jsonl`, исходники не трогает. Без этого шага половина негативного класса —
   обрывы сохранения, а не выдумки; именно так и появились завышенные числа в §21.
3. `score_all.ts` — прогоняет ответы через рантайм-скорер
   (`packages/core/src/truthprobe/score.ts`), пишет `rows_scored2.jsonl` / `rows_scored3.jsonl`.
   По умолчанию читает уже восстановленные `*f.jsonl`.
4. `dataset.py` — 30 признаков из токенов и текста → `dataset.jsonl` (`y = 1` для ложного).
5. `eval.py` — то, что имеет смысл публиковать: базлайны, обученные модели, контроль длины
   (ортогонализация по `n_tokens` внутри фолда), AUROC по категориям и квартилям длины,
   кластерный бутстрэп по `qid` для доверительных интервалов.
6. `train.py` — логистика, CART, лес, мини-MLP на stdlib, `GroupKFold` по `qid`,
   с признаками длины и без; пишет `model.json`. Это разведка, не публикуемый результат.
7. `ablate.py` — абляции и `leave-one-model-out`.
8. `thresholds.py` — доли ложных/верных ниже порогов продукта.

Числа и оговорки — `docs/VALIDATION.md` §22 (в §21 опубликованы отозванные значения:
там негативный класс наполовину состоял из пустых ответов). Краткий вывод — `docs/LEARNED-WEIGHTS.md`:
обученные веса не превосходят встроенную формулу, поэтому в поставку не входят.
